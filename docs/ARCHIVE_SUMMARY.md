# Documentation Organization Summary

This document provides an overview of the documentation structure in the StillOnTime repository.

## Current Active Documentation

### Root Level
- `README.md` - Main project documentation and quick start guide
- `AGENTS.md` - Development guide with project-specific patterns and workflows
- `CLAUDE.md` - Claude Code configuration and development environment setup
- `PERFORMANCE_OPTIMIZATION_SUMMARY.md` - Performance optimization results
- `PRIVACY_POLICY.md` - Privacy policy document
- `COMPLETE-DEPLOYMENT-GUIDE.md` - Complete deployment guide (GLM 4.6 + Claude Code)

### Documentation Directory (`docs/`)
- **API Documentation**: `API_REFERENCE.md`
- **Deployment**: `DEPLOYMENT_GUIDE.md`
- **Security**: `SECURITY_QUICK_REFERENCE.md`, `SECURITY_AUDIT_REPORT.md`
- **Admin**: `ADMIN_MANUAL.md`
- **Architecture**: `architecture/` - System architecture documents
- **Specifications**: `sparc-specification/` - Complete SPARC specifications
- **Performance**: `performance/` - Performance guides and monitoring
- **CodeNet**: `PROJECT_CODENET_INTEGRATION.md`, `CODENET_UNIVERSAL_DEPLOYMENT_GUIDE.md`
- **Migration Guides**: `PRISMA_REMOVAL_GUIDE.md`, `KYSELY_MIGRATION_COMPLETE.md`

## Archived Documentation

All historical documentation, session summaries, task reports, and implementation summaries have been moved to `docs/archive/` for reference.

See [docs/archive/README.md](./archive/README.md) for details about archived documents.

## Documentation Maintenance

- **Current docs** are actively maintained and referenced in the main README
- **Archived docs** are preserved for historical reference but not actively maintained
- When updating documentation, ensure references in README.md are current
- New documentation should be placed in appropriate `docs/` subdirectories
